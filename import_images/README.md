# 📸 คู่มือการนำเข้าภาพและคู่มือการตั้งชื่อไฟล์ (Image Import & Naming Guide)

โฟลเดอร์นี้ (`import_images/`) จัดทำขึ้นเพื่อให้คุณสามารถนำไฟล์ภาพถ่ายจริง หรือภาพที่เจนจาก AI (เช่น ChatGPT / Midjourney) มาใส่ไว้เพื่อนำเข้าไปใช้งานในระบบจำลองการพยาบาล **BreathQuest** ได้ทันที

---

## 📁 โครงสร้างโฟลเดอร์สำหรับใส่ภาพ (Folder Structure)

```text
import_images/
├── patients/      <-- ภาพผู้ป่วยจำลองทางคลินิกประจำแต่ละห้อง
├── equipment/     <-- ภาพอุปกรณ์และเครื่องมือทางการแพทย์
├── badges/        <-- ภาพตราสัญลักษณ์รางวัลการเรียนรู้ (Badges)
├── procedures/    <-- ภาพขั้นตอนหัตถการและการจัดท่าผู้ป่วย
└── scenarios/     <-- ภาพบรรยากาศห้องผู้ป่วยและหอผู้ป่วยจำลอง
```

## 🚀 วิธีการนำภาพเข้าสู่ระบบ (How to Sync)

เมื่อคุณวางไฟล์ภาพลงในโฟลเดอร์ย่อยใน `import_images/` เรียบร้อยแล้ว ให้รันคำสั่งเพียงบรรทัดเดียวใน Terminal:

```bash
python sync_images.py
```

คำสั่งนี้จะทำสิ่งต่อไปนี้ให้อัตโนมัติ:
1. ตรวจสอบไฟล์ภาพและแปลงนามสกุลให้อยู่ในรูปแบบที่ระบบรองรับ
2. ปรับขนาดภาพ (Resize) และบีบอัดขนาดไฟล์ให้เหมาะสมกับการโหลดบนเว็บเบราว์เซอร์และแท็บเล็ต
3. คัดลอกไปยัง `app/static/images/` ของระบบทันที
